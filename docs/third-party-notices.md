# Third-party software and assets

The MIT license covers this project's own code and synthetic examples. It does
not grant rights to model weights, source footage, identities, voices, stock media,
or externally installed tools. Check each exact version and model's terms before use.

The runtime integrates independently installed FFmpeg, yt-dlp, Demucs, WhisperX,
llama.cpp/Qwen, Chatterbox, optional CosyVoice, and optional MuseTalk. These packages
and their models are not vendored in this source release. Dependency declarations
point to their respective distributions or upstream repositories.

Media providers include Pexels, Pixabay, Wikimedia Commons, Library of Congress,
and Jamendo. Asset-specific rights and attribution remain necessary. NARA live
access is disabled. Keep generated license and credit reports with exported media.

An optional local 2D rendering plugin is excluded from the public distribution
because its supplied archive did not include a redistribution license. It is not
a dependency of the Python package or the main pipeline.
