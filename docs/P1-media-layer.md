# Media layer

Visual requests pass through planning, provider routing, license checks, bounded downloads, media validation, and rebuild. Supported providers are configurable; missing keys disable optional sources. Unsafe or unverifiable material is rejected as `no_safe_match`. NARA live access remains disabled. Review asset-specific rights and the generated credit reports.

See [installation](installation.md), [usage](usage.md), and [release verification](release.md).
